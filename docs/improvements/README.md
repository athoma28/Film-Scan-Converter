# Product Planning

The [Native macOS Product Roadmap](MacOS-Native-Roadmap.md) is the single ordered
plan. Keep only remaining work there, with concrete acceptance conditions.

[Development status](../development/native-macos.md) owns implemented behavior,
current evidence, and limitations. [Features](../features.md) owns user-visible
claims. Dated performance reports retain measurements needed for reproducibility;
they do not create another implementation queue.

New features belong in the native app. [Python maintenance](../legacy-python.md)
and [parked calibration research](../film-processing-research.md) have separate,
explicit boundaries.
